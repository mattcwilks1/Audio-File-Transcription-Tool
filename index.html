Transcribe large audio files

Drop an audio file anywhere on this page — meetings, interviews, hearings, podcasts. Hours-long files are fine: they're processed in 30-second chunks and the transcript streams in live.

  1. Open (or drop) an audio file
  2. Pick a model — Base English is a good default
  3. Press Transcribe, watch text appear; export TXT / SRT / VTT
